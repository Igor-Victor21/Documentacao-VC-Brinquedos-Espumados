# Serviços Externos

### Cloudinary

Utilizado para armazenamento de imagens dos produtos enviadas pelo dashboard, retornando a URL que é posteriormente salva no banco de dados.

A escolha do Cloudinary foi feita pela facilidade de integração com Node.js, além de oferecer otimização automática de imagens e boa performance na entrega de conteúdo.

Essa integração facilitou muito o gerenciamento de produtos, evitando a necessidade de armazenar arquivos diretamente no backend ou utilizar soluções mais complexas.

---

### Firebase

Utilizado principalmente para autenticação de usuários e gerenciamento do banco de dados com Firestore.

A escolha foi baseada na praticidade da plataforma, que oferece diversas funcionalidades integradas, como autenticação, segurança e banco de dados em tempo real, além de ser totalmente gerenciada.

Isso permitiu acelerar o desenvolvimento e reduzir a complexidade da infraestrutura.
